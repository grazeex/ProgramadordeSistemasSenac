# Sistemas de Informação - Conceitos e Tipos
## Definição de sistemas de informação
- Um sistema de informação (SI) é um conjunto de componentes inter-relacionados que coletam, processam, armazenam e distribuem informações para apoiar a tomada de decisões e o controle em uma organização.
  
## Importância dos sistemas de informação nas organizações
- Os sistemas de informações são fundamentais nas organizações porque coletam, processam, armazenam e distribuem dados para otimizar processos e orientar a tomada de decisões.

# Tipos de Sistemas de Informação

## 1. Sistemas de Processamento de Transações (SPT)
- **Objetivo**: Processar e registrar transações diárias da organização
- **Usuários**: Funcionários operacionais de linha de frente
- **Exemplos**: Sistemas de vendas, folha de pagamento, controle de estoque
- **Características**: Processamento em tempo real, alta volume de dados, operacional

## 2. Sistemas de Informação Gerencial (SIG)
- **Objetivo**: Fornecer informações para planejamento, controle e decisões gerenciais
- **Usuários**: Gerentes e supervisores
- **Exemplos**: Relatórios de vendas, análise de custos, dashboard de desempenho
- **Características**: Informações consolidadas, periodicidade média, tático

## 3. Sistemas de Suporte à Decisão (SSD)
- **Objetivo**: Auxiliar executivos e gerentes em decisões não estruturadas e complexas
- **Usuários**: Executivos e analistas
- **Exemplos**: Simuladores financeiros, análise de cenários, ferramentas de previsão
- **Características**: Análise avançada, dados históricos e atuais, interativo

## 4. Sistemas de Informação Executiva (EIS)
- **Objetivo**: Fornecer visão geral dos negócios para tomada de decisão estratégica
- **Usuários**: Diretores e executivos sênior
- **Exemplos**: Dashboards executivos, KPIs estratégicos, relatórios consolidados
- **Características**: Visão estratégica, dados agregados, interface amigável
